## 무엇을 했나

부지에 태양광·풍력 발전설비를 지을 때 **주거지·도로로부터 몇 m 떨어져야 하는지(이격거리)** 를
자동으로 판정하는 기능을 추가했다. 판정표에 `이격거리 규정` 행이 새로 생긴다.

근거 법령은 두 겹이다.
- **상위법**: 「신에너지 및 재생에너지 개발·이용·보급 촉진법」 제27조의3 (**시행 2026-09-18**)
  — 원칙적으로 이격거리 규제를 금지하되 예외를 둔다
- **조례**: 각 시·군의 개발행위허가 운영지침 등에 규정된 실제 이격거리 수치

시행일 전후로 판정 결과가 달라지므로, **판정 기준일(`apply_date`)** 을 입력받아
그 날짜 기준으로 계산하고 결과에 함께 표시한다.

## 핵심 설계 원칙

**확실하지 않으면 절대 "비저촉"을 내지 않는다.**
조례 수치를 모르거나, 값을 해석할 수 없거나, 보호구역 해당 여부를 알 수 없으면
전부 `판정불가` 또는 `조건부`로 떨어뜨려 사람이 확인하도록 한다.
판정 엔진(`src/setback_check.py`)은 구조적으로 `저촉`을 반환하지 않는다 —
법적 책임이 걸린 단정은 도구가 내리지 않는다.

같은 이유로, 이격거리 행은 **판정할 수 없을 때도 행 자체를 반드시 출력**한다.
행이 통째로 빠지면 "검토했더니 문제없음"과 "애초에 검토를 안 함"을 구분할 수 없기 때문이다.
