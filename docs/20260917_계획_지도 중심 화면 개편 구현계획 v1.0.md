# 지도 중심 화면 개편 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 첫 화면부터 지도가 보이고 용도지역이 색으로 구분되며, 지도를 클릭하면 바로 판정되는 3단 레이아웃으로 `public/index.html`을 개편한다.

**Architecture:** 용도지역 레이어는 브라우저가 Supabase RPC(`zoning_in_bbox`)를 직접 호출해 받는다(Vercel 미경유). 판정은 기존대로 `/api/site_judge`를 거친다. 표시용 도형(단순화)과 판정용 도형(원본 정밀도)을 분리해, 화면에 그리는 뭉뚱그린 경계로는 절대 판정하지 않는다.

**Tech Stack:** Leaflet 1.9.4(CDN), V-World WMTS 위성타일, Supabase PostgREST, Python 3.14 + pytest, Node 24 내장 `node --test`(패키지 추가 없음)

**Spec:** [docs/20260917_설계_지도 중심 화면 개편 v1.0.md](20260917_설계_지도%20중심%20화면%20개편%20v1.0.md)

## Global Constraints

- **판정에 단순화 도형을 쓰지 않는다.** `zoning_in_bbox`의 결과는 화면 렌더링 전용이다. 판정은 `/api/site_judge`가 `zone_at`(원본 정밀도)으로 수행한다.
- **`api/` 폴더에 handler 파일을 추가하지 않는다.** 이 Vercel 프로젝트는 `pyproject.toml`의 `[tool.vercel] entrypoint = "api.site_judge:handler"`로 단일 진입점이 고정돼 있다. 파일을 늘리면 라우팅이 깨진다. 새 엔드포인트는 `site_judge.py` 안에서 `self.path` 분기로 만든다.
- **브라우저에 `SUPABASE_SECRET_KEY`를 절대 내려보내지 않는다.** 클라이언트에는 `SUPABASE_PUBLISHABLE_KEY`만 전달한다.
- **확실하지 않으면 "비저촉"을 내지 않는다.** 기존 원칙 유지.
- 대상 지역은 **전남 22개 시군**뿐이다.
- Vercel Hobby: 함수 실행 10초. Supabase 무료: 1주일 미사용 시 프로젝트 정지.
- 지원 브라우저 폭: 최소 360px까지 가로 스크롤 없이 동작.
- 기존 명령은 그대로 동작해야 한다: `python -m pytest -v` (현재 133 passed).

### Task 1: 지도 순수 함수와 테스트

줌 판단·단순화 강도·색 매핑은 틀려도 화면이 그럴듯하게 그려져서 눈으로 못 잡는다. 순수 함수로 떼어내 고정한다.

**Files:**

**Interfaces:**
- Consumes: 없음

`public/map_utils.js`:

```javascript
// 지도 표시용 순수 함수. 판정에는 관여하지 않는다.
// 브라우저(<script>)와 Node 테스트(require) 양쪽에서 쓰기 위해 UMD 형태로 노출한다.
(function (root, factory) {
  const api = factory();
  if (typeof module === "object" && module.exports) module.exports = api;
  else root.MapUtils = api;
})(typeof self !== "undefined" ? self : this, function () {
  // 줌 11 이하(전남 전체 조망)에서는 아예 로드하지 않는다. 8만 폴리곤을 한 화면에
  // 그리면 뭉개져서 읽을 수 없고 브라우저만 멈춘다.
  const MIN_ZONING_ZOOM = 12;

  // 단순화 강도(도 단위). 0.0001도 ~= 11m.
  // 확대할수록 작게 줘서 경계선을 정확히 보여준다.
  const TOLERANCE_BY_ZOOM = [
    { minZoom: 16, tolerance: 0.00005 },  // 필지 단위 (~5.5m)
    { minZoom: 14, tolerance: 0.0002 },   // 읍면 단위 (~22m)
    { minZoom: 12, tolerance: 0.0005 },   // 시군 단위 (~55m)
  ];

  // 국토계획법 용도지역 체계에 맞춘 6색 + 중립 회색.
  // 위성사진 위에 얹히므로 채도가 높고 서로 명도가 충분히 다른 색을 고른다.
  const CATEGORY_COLORS = {
    "주거지역": "#e8913a",
    "상업지역": "#d6455d",
    "공업지역": "#8a5bd6",
    "녹지지역": "#4ba35a",
    "관리지역": "#2f8fd0",
    "농림·자연환경보전지역": "#1d6b52",
    "미분류": "#8a8f98",
  };
  const FALLBACK_COLOR = "#8a8f98";
  const ZONE_CATEGORIES = Object.keys(CATEGORY_COLORS);

  function shouldLoadZoning(zoom) {
    return zoom >= MIN_ZONING_ZOOM;
  }

  function toleranceForZoom(zoom) {
    for (const step of TOLERANCE_BY_ZOOM) {
      if (zoom >= step.minZoom) return step.tolerance;
    }
    return TOLERANCE_BY_ZOOM[TOLERANCE_BY_ZOOM.length - 1].tolerance;
  }

  function categoryColor(category) {
    return CATEGORY_COLORS[category] || FALLBACK_COLOR;
  }

  return {
    MIN_ZONING_ZOOM, ZONE_CATEGORIES,
    shouldLoadZoning, toleranceForZoom, categoryColor,
  };
});
```

import importlib.util
import sys
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(BASE_DIR / "src"))


def load_api(monkeypatch=None):
    spec = importlib.util.spec_from_file_location("site_judge_api", BASE_DIR / "api" / "site_judge.py")
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


def test_config_includes_supabase_url_and_publishable_key(monkeypatch):
    monkeypatch.setenv("SUPABASE_URL", "https://example.supabase.co")
    monkeypatch.setenv("SUPABASE_PUBLISHABLE_KEY", "pub-key")
    api = load_api()

    config = api.build_config()

    assert config["supabase_url"] == "https://example.supabase.co"
    assert config["supabase_key"] == "pub-key"


def test_config_never_exposes_the_secret_key(monkeypatch):
    """secret 키는 RLS를 무시하는 전권 키다. 브라우저로 나가면 누구나 데이터를 지울 수 있다."""
    monkeypatch.setenv("SUPABASE_SECRET_KEY", "super-secret-value")
    monkeypatch.setenv("SUPABASE_PUBLISHABLE_KEY", "pub-key")
    api = load_api()

    config = api.build_config()

    assert "super-secret-value" not in str(config)

```javascript
  // 화면 범위의 용도지역을 Supabase에서 직접 받아 칠한다.
  // 여기서 받는 도형은 단순화된 표시용이다 - 판정에는 절대 쓰지 않는다(설계서 §4.4).
  // 줌 12에서 단순화 오차가 55m까지 나므로, 경계 근처는 화면 색과 실제 판정이 다를 수 있다.
  async function loadZoning() {
    if (!document.getElementById("layer-zoning").checked) {
      if (zoningLayer) { leafletMap.removeLayer(zoningLayer); zoningLayer = null; }
      notice("");
      return;
    }
    const zoom = leafletMap.getZoom();
    if (!shouldLoadZoning(zoom)) {
      if (zoningLayer) { leafletMap.removeLayer(zoningLayer); zoningLayer = null; }
      notice("확대하면 용도지역이 표시됩니다");
      return;
    }
    if (!cfg.supabase_url || !cfg.supabase_key) {
      notice("용도지역 레이어를 불러오지 못했습니다 (설정 없음). 판정은 그대로 됩니다.");
      return;
    }

    const myId = ++zoningRequestId;   // 지도를 빠르게 움직이면 늦게 온 응답이 최신을 덮어쓴다
    const b = leafletMap.getBounds();
    try {
      const res = await fetch(cfg.supabase_url.replace(/\/$/, "") + "/rest/v1/rpc/zoning_in_bbox", {
        method: "POST",
        headers: {
          "apikey": cfg.supabase_key,
          "Authorization": "Bearer " + cfg.supabase_key,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          min_lon: b.getWest(), min_lat: b.getSouth(),
          max_lon: b.getEast(), max_lat: b.getNorth(),
          tolerance: toleranceForZoom(zoom),
          max_rows: MAX_ZONING_ROWS,
        }),
      });
      if (!res.ok) throw new Error("HTTP " + res.status);
      const rows = await res.json();
      if (myId !== zoningRequestId) return;   // 더 새로운 요청이 진행 중

      if (zoningLayer) leafletMap.removeLayer(zoningLayer);
      zoningLayer = L.layerGroup(rows.map(function (row) {
        const color = categoryColor(row.zone_category);
        return L.geoJSON(JSON.parse(row.geojson), {
          style: { color: color, weight: 1, fillColor: color, fillOpacity: 0.35 },
        }).bindTooltip(row.zone_name, { sticky: true });
      })).addTo(leafletMap);

      // 3,000건에서 잘렸을 수 있다. 조용히 자르면 사용자가 빈 곳을 보고
      // "용도지역이 없는 땅"으로 오해한다.
      notice(rows.length >= MAX_ZONING_ROWS
        ? "이 범위에는 표시할 수 있는 것보다 많은 구역이 있습니다 — 확대하세요" : "");
    } catch (e) {
      if (myId !== zoningRequestId) return;
      // 레이어 실패가 판정을 막지 않는다. 둘은 다른 경로다.
      notice("용도지역 레이어를 불러오지 못했습니다 (" + e.message + "). 판정은 그대로 됩니다.");
    }
  }

  leafletMap.on("moveend", loadZoning);
  document.getElementById("layer-zoning").addEventListener("change", loadZoning);
  document.getElementById("layer-satellite").addEventListener("change", function () {
    if (!tileLayer) return;
    if (this.checked) tileLayer.addTo(leafletMap); else leafletMap.removeLayer(tileLayer);
  });
```

def missing_input_reason(query: dict):
    """판정에 필요한 입력이 없으면 사유를, 있으면 None을 돌려준다.

    지도 클릭은 주소 문자열 없이 좌표만 보낸다. 주소를 필수로 두면 클릭 판정이 막힌다.
    """
    address = (query.get("address") or [""])[0].strip()
    lon = (query.get("lon") or [""])[0].strip()
    lat = (query.get("lat") or [""])[0].strip()
    if address or (lon and lat):
        return None
    return "주소 또는 좌표(lon/lat)가 필요합니다"

      (row["출처"] ? '<p class="foot"><a href="' + escapeAttr(row["출처"]) + '" target="_blank">조례 원문</a></p>' : "");
  }

  function escapeHtml(text) {
    return String(text == null ? "" : text).replace(/[&<>"']/g, function (ch) {
      return { "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" }[ch];
    });
  }
  function escapeAttr(text) { return String(text == null ? "" : text).replace(/"/g, "&quot;"); }
```

def route_for(path: str) -> str:
    """요청 경로 -> 처리 이름.

    이 Vercel 프로젝트는 api/ 에 handler 파일을 하나만 둘 수 있어서(pyproject.toml의
    entrypoint로 고정) 엔드포인트를 파일로 늘릴 수 없다. 경로로 분기한다.
    """
    return "law" if urlparse(path).path.rstrip("/").endswith("/law") else "judge"


def fetch_law(query: dict) -> dict:
    """판정 근거 조문의 원문을 law.go.kr에서 실시간 조회한다.

    규칙표(rule_table.csv)에도 발췌본이 있지만 담아둔 시점의 사본이다. 법령 탭은
    지금 시행 중인 원문을 보여주는 것이 목적이므로 매번 새로 가져온다.
    """
    law_name = (query.get("law_name") or [""])[0].strip()
    law_article = (query.get("law_article") or [""])[0].strip()
    if not law_name or not law_article:
        return {"status": "no_data", "reason": "law_name과 law_article이 필요합니다"}
    try:
        return lookup_article_text(law_name, law_article)
    except Exception as e:
        return {"status": "no_data", "reason": f"조문 조회 실패: {type(e).__name__}: {e}"}
```

  const LAW_PATTERN = /([가-힣ㆍ·\s]+(?:법|법률|조례|규칙|시행령|시행규칙))\s*(제\d+조(?:의\s*\d+)?|별표\s*\d+)/;

  async function loadLawTab() {
    const el = document.getElementById("tab-법령");
    if (!lastData || !lastData.table || !lastData.table.length) {

    el.innerHTML = '<p class="foot">조문을 불러오는 중...</p>';
