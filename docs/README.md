# docs

## 폴더 목적/용도
기능별 설계서(스펙)를 모아두는 폴더. 구현 전에 합의한 설계를 문서로 남겨, 나중에 "왜 이렇게 만들었는지"를 코드가 아닌 근거 문서로 추적할 수 있게 한다.

`PRD.md`(제품 전체 명세)와의 차이: PRD는 시스템 전체의 기능요구사항 목록이고, 이 폴더는 **개별 기능 하나를 구현하기 전에 쓰는 상세 설계서**다. 구현이 끝나면 PRD.md의 해당 FR 항목에 "구현 완료"로 반영하고, 상세 근거는 이 문서를 링크한다.

## 폴더 내 규칙
- 파일명은 상위 [산출물 저장 규칙](../../../CLAUDE.md#산출물-저장-규칙)을 따른다: `yyyymmdd_카테고리_파일명 버전(v1.0).확장자`
- 카테고리는 `설계`를 쓴다
- 설계가 바뀌면 같은 파일의 버전을 올린다(v1.1, v2.0). 구현 중 설계와 달라진 부분은 문서에 반영한 뒤 구현을 이어간다
- 법령 조문 등 외부 근거를 인용할 때는 **조회 시점과 출처 URL을 함께** 적는다. 법령은 개정되므로 "언제 기준의 조문인지"가 없으면 근거로서 가치가 없다
