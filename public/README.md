# public

## 폴더 목적/용도
Vercel에 배포되는 정적 프론트엔드 파일. 신재생사업본부 팀원들이 접속하는 실제 웹 화면.

## 폴더 생성일
2026-09-16 (`webapp/public/`에서 프로젝트 루트로 이동, 2026-09-16)

## 폴더 내 규칙
특별한 파일명 규칙 없음 — 상위 [산출물 저장 규칙](../CLAUDE.md#산출물-저장-규칙)을 따르되, 이 폴더는 배포되는 웹 화면 그 자체이므로 예외로 둔다.

## 폴더 내 파일
- `index.html`: 메인 페이지. 부지 주소/사업 종류/용량을 입력하면 `/api/site_judge`를 호출해 판정표를 렌더링한다.
- `guestbook.html`: 방명록 페이지 (강사 요구사항). Supabase 연동 — 상단의 `SUPABASE_URL`/`SUPABASE_KEY`를 채워야 동작한다. 비워두면 "연결 안 됨" 안내만 표시되고 앱은 정상 동작함(HANDOVER.md 참고).
